## Задание

Велопрокат готовит отчёт о доступных велосипедах.

Файл содержит название модели, тип велосипеда, число доступных экземпляров и стоимость одного часа проката в рублях.

Необходимо:

1. Вывести сведения о велосипедах задаваемого типа.
    
2. Определить, сколько экземпляров можно выдать одновременно.
    
3. Рассчитать выручку за час, если все велосипеды выбранного типа будут выданы.
    
4. Найти среди всех моделей велосипед с самой низкой стоимостью часа проката.
    

## Описание программы

Для хранения информации об одном велосипеде используется структура `Bicycle`, содержащая название модели, тип, количество доступных экземпляров и цену проката.

Все записи хранятся в `vector<Bicycle>`.

Программа использует отдельные функции:

- `splitFields()` — разделение строки на поля.
    
- `readInteger()` и `readDouble()` — преобразование и проверка чисел.
    
- `readBicycles()` — чтение и проверка данных файла.
    
- `calculateStatistics()` — вычисление количества велосипедов, выручки и минимальной цены.
    
- `createReport()` — формирование текстового отчёта.
    
- `writeReport()` — запись отчёта в файл.
    

## Входные данные

Программа запрашивает:

1. Путь к исходному текстовому файлу.
    
2. Путь к выходному файлу.
    
3. Тип велосипеда для поиска.
    

В исходном файле каждая строка содержит одну запись. Поля разделяются символом `;`.

Формат:

`Модель;Тип;Количество;Цена`

Файл содержит не более 100 записей. Количество и стоимость проката не могут быть отрицательными.

## Пример входного файла

**input.txt**

```
Trek Marlin 5;Mountain;4;250
Giant Escape 3;City;3;180
Scott Aspect 950;Mountain;2;300
Merida Big Nine;Mountain;5;220
Stels Navigator;City;6;150
```

## Пример работы

**Ввод в консоль:**

```
input.txt
output.txt
Mountain
```

**Вывод:**

```
Type: Mountain
Bicycles:
Trek Marlin 5;Mountain;4;250
Scott Aspect 950;Mountain;2;300
Merida Big Nine;Mountain;5;220
Available: 11
Revenue per hour: 2700
Cheapest: Stels Navigator; 150
```

Для выбранного типа доступно 11 велосипедов. Общая выручка за один час составляет 2700 рублей.

Самая дешёвая модель среди всех записей — Stels Navigator, стоимость проката составляет 150 рублей в час.

## Обработка ошибок

Программа предусматривает следующие сообщения:

- `ERROR input` — не удалось открыть входной файл.
    
- `ERROR line N` — некорректные данные в строке N.
    
- `ERROR read` — ошибка чтения файла.
    
- `ERROR output` — не удалось открыть выходной файл.
    
- `ERROR write` — ошибка записи отчёта.
    
- `INVALID` — некорректные параметры запуска.
    

Если велосипеды заданного типа отсутствуют, выводится `EMPTY`. При отсутствии моделей в файле вместо самой дешёвой модели выводится `NONE`.
